## 已知限制和处理原则

范围限单机、当前 Windows 用户、本人单个微信账号及文字，支持在明确指定的本机已有项目内新建聊天；不支持群聊/媒体/从微信新建项目或 worktree，不远程执行任意 shell，不另开 Codex 模型进程。

提交或送达未知不盲重发。status 分别展示 unknownSubmissions、undelivered、observationGaps；notifications 显示通知内容与原因，retry-notification 先显示记录、提醒可能重复，输入 resend 才对允许状态重排通知，不能因此重提 Codex 要求。成功回执只代表微信接口接受。

当前只确认 -14 为账号凭据失效，未证实服务端 context 失效码；不按错误文字猜测并自动恢复。没有上下文时保留未发送通知，本人新消息刷新后继续；已未知/明确拒绝的记录依状态提示核对或手动处理。

正文维护分别保留最近1000条已结束入站和已接受/取消通知正文，较旧正文清除；未解决记录及已完成 ID tombstones 仍保留防重复。去重 ID 并非有限清理，不承诺存储总量固定。

不承诺永久 token、任意时长主动通知、断线期间即时送达、exactly-once 或桌面内部协议跨版本兼容。
