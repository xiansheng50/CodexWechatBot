# CodexWechatBot：用微信继续你的 Codex 工作

CodexWechatBot 是一个连接本人微信 ClawBot 与电脑上 Codex Desktop 的小工具。安装并绑定后，你可以在微信里继续电脑上的聊天、补充要求，并在任务结束后接收结果摘要或简短结束通知。

例如，你在电脑上让 Codex 检查一个项目，离开电脑后，可以用微信发送“继续检查这个问题”，也可以等它完成后查看通知。任务仍在原来的 Codex 聊天中进行，沿用该聊天的模型、上下文和权限设置。

## 它能做什么

- **继续已有聊天**：从微信给选中的 Codex 聊天发送文字要求，聊天正在执行时也能补充要求。
- **选择不同聊天**：查看聊天列表，通过编号切换目标，或临时向某个聊天发送一条消息。
- **创建新聊天**：提供首条要求，从微信新建无项目聊天，也可以指定电脑上已有的项目；创建成功后，后续普通消息会自动发给它。
- **接收完成通知**：为某个聊天开启通知后，无论任务从微信还是电脑发起，轮次结束后都会按全局模式，尝试把最终回复摘要或简短结束通知发到微信。

微信发起的要求，即使没有开启持续通知，也会按全局模式返回结果或结束通知。持续通知主要用于接收电脑端发起任务的后续结果。

## 怎样开始使用

1. 准备一台联网的 Windows 电脑，安装并登录 Codex Desktop；运行环境以 Node.js 24 为已验证基线。
2. 把[仓库地址](https://github.com/xiansheng50/CodexWechatBot)交给这台电脑上的 Codex，并明确要求：“请按仓库中的新设备操作文档，安装并运行这个项目。”仓库为私有仓库，需要有访问权限的 GitHub 账号。
3. 按提示完成必要的授权、微信扫码和 Codex 重启，然后在手机 ClawBot 发送“帮助”，确认能够收到回复。
4. 在想使用的 Codex 聊天里说：“把这个聊天设为微信消息目标，并开启这个聊天的微信完成通知。”再从微信发送“状态”和一条普通文字，确认收发正常。

克隆、安装和配置可以交给 Codex 操作；账号授权、扫码和手机收发确认仍需要本人参与。详细步骤见[新设备安装与运行文档](new-device-setup.md)。

## 微信里常用的命令

| 发送内容 | 用途 |
| --- | --- |
| `帮助` | 查看可用命令。 |
| `状态` | 查看连接情况、当前聊天目标、全局通知模式和通知状态。 |
| `列表` | 查看可发现的聊天及编号，较多时可发送 `列表 2` 翻页。 |
| `切换 #3` | 把普通消息目标切换为编号 3 的聊天，开启它的持续通知并关闭原目标的持续通知。 |
| `#3 请继续检查` | 只把这一条发给编号 3 的聊天，不改变普通消息目标。 |
| `通知 #3 开` / `通知 #3 关` | 开启或关闭编号 3 的聊天的持续完成通知。 |
| `模式 结果` / `模式 仅通知` | 切换全局结束通知内容，默认结果模式，重启后保留。 |
| `项目` | 查看新设备上可用的本地项目。 |
| `新建｜你的要求` | 新建不属于任何项目的聊天，并自动切换到它。 |
| `新建 项目名｜你的要求` | 在指定项目新建聊天，并自动切换到它。 |

**不带编号的普通文字，会发给上次明确选择的聊天。** 编号以实际“列表”为准；收到其他聊天的通知不会改变当前目标。新建或切换成功后，默认开启目标聊天的持续完成通知并关闭原目标的持续通知，其他单独开启的订阅保留。手动关闭后不会因普通消息或重启重新开启；下次明确选择该聊天时再次开启。旧聊天里已经提交的微信要求仍会按全局模式返回结果或结束通知。

## 使用时需要知道的事

- **电脑需要保持联网、唤醒，Codex 和桥接服务需要运行。** 它不是云端代跑服务；电脑睡眠或关机期间不能即时处理消息。正常加载项目入口后，会按需启动桥接服务。
- 当前面向 Windows、本人单个微信账号和文字消息，不支持群聊、图片、语音或远程处理 Codex 审批；遇到需要审批的操作，仍需回电脑处理。
- 默认结果模式发送最终回复摘要，长内容需要回桌面查看；仅通知模式只显示聊天和结束状态，不发送回复正文。模式切换对之后生成的结束通知生效，已生成的通知保持原内容；“本轮已结束”也不代表每项业务要求都已成功。
- 网络或登录异常可能造成延迟或无回复。先查看“状态”和原聊天，不要因为没收到回复就连续重复发送同一要求。
- 换电脑需要在新设备重新完成安装、绑定和聊天选择；同一微信切换设备前先停止旧电脑的桥接，避免两个接收者同时运行。

项目在本机运行，微信凭据和聊天路由记录保存在本机，不需要另外部署服务器或申请额外的模型账号。消息仍会经过微信和 Codex 处理，请按日常使用这两个服务的方式保护自己的信息。
